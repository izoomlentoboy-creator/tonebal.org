# 🔔 Настройка Webhook YooKassa для tonebal.org

## 📋 Что такое Webhook?

Webhook (веб-хук) — это механизм, с помощью которого YooKassa автоматически уведомляет ваш сервер об изменениях статуса платежей. Вместо того чтобы постоянно опрашивать API YooKassa, ваш сервер получает уведомления сразу после события (успешная оплата, отмена, возврат).

## ✅ Требования YooKassa к Webhook

Согласно [официальной документации](https://yookassa.ru/developers/using-api/webhooks):

1. **HTTPS обязателен** - URL должен использовать протокол HTTPS
2. **Порт 443 или 8443** - стандартные порты для HTTPS
3. **TLS/SSL 1.2+** - поддержка современных версий TLS/SSL
4. **HTTP 200 ответ** - сервер должен возвращать код 200 для подтверждения получения
5. **Быстрый ответ** - рекомендуется отвечать в течение 10 секунд
6. **Идемпотентность** - обработка повторных уведомлений должна быть безопасной

## 🔧 Что было реализовано в коде

### В файле `server.js`:

1. **Проверка типа уведомления**
   ```javascript
   if (type !== 'notification') {
       return res.status(400).json({ error: 'Invalid notification type' });
   }
   ```

2. **Проверка IP-адреса отправителя** (опционально, закомментировано)
   ```javascript
   // Список разрешенных IP YooKassa
   const YOOKASSA_IPS = [
       '185.71.76.0/27',
       '185.71.77.0/27',
       '77.75.153.0/25',
       '77.75.156.11',
       '77.75.156.35',
       '77.75.154.128/25',
       '2a02:5180::/32'
   ];
   ```

3. **Верификация через API** - проверка подлинности уведомления
   ```javascript
   const verifiedPayment = await verifyNotification(object?.id);
   ```

4. **Обработка всех событий**:
   - `payment.succeeded` - успешная оплата
   - `payment.canceled` - отмена платежа
   - `payment.waiting_for_capture` - ожидание подтверждения
   - `refund.succeeded` - успешный возврат

5. **Всегда возвращает HTTP 200** - даже при ошибках, чтобы избежать повторных отправок

## 🚀 Пошаговая настройка Webhook в YooKassa

### Шаг 1: Убедитесь, что проект развернут

Ваш сервер должен быть доступен по адресу:
```
https://tonebal.org
```

Проверьте работоспособность:
```bash
curl https://tonebal.org/api/health
```

Должен вернуть:
```json
{
  "status": "ok",
  "timestamp": "2026-01-26T...",
  "baseUrl": "https://tonebal.org",
  "shopId": "513198"
}
```

### Шаг 2: Войдите в личный кабинет YooKassa

1. Откройте https://yookassa.ru/my
2. Войдите с вашими учетными данными

### Шаг 3: Перейдите в раздел HTTP-уведомлений

1. В левом меню выберите **"Интеграция"**
2. Затем **"HTTP-уведомления"**

### Шаг 4: Добавьте URL для уведомлений

В поле **"URL для уведомлений"** введите:
```
https://tonebal.org/api/webhooks/yookassa
```

**Важно:**
- URL должен начинаться с `https://`
- Порт должен быть 443 (по умолчанию для HTTPS)
- Путь должен быть точно `/api/webhooks/yookassa`

### Шаг 5: Выберите события для отслеживания

Отметьте галочками следующие события:

- ✅ **payment.succeeded** - платёж успешно завершён
- ✅ **payment.canceled** - платёж отменён
- ✅ **payment.waiting_for_capture** - платёж ожидает подтверждения (опционально)
- ✅ **refund.succeeded** - возврат успешно выполнен

### Шаг 6: Сохраните настройки

Нажмите кнопку **"Сохранить"** внизу страницы.

## 🧪 Тестирование Webhook

### Метод 1: Тестовый платеж

1. Откройте страницу оплаты:
   ```
   https://tonebal.org/pay?nosology=paresis&user_id=test123
   ```

2. Используйте тестовую карту:
   - Номер: `5555 5555 5555 4477`
   - Срок: любая будущая дата
   - CVC: любые 3 цифры

3. Завершите оплату

4. Проверьте логи сервера - должно появиться сообщение:
   ```
   Webhook received from IP: ...
   Webhook event: payment.succeeded, payment ID: ...
   ✅ Subscription activated: test123 -> paresis until ...
   ```

### Метод 2: Проверка через логи Vercel

1. Откройте https://vercel.com/dashboard
2. Выберите ваш проект
3. Перейдите в **Logs**
4. Выполните тестовый платеж
5. В логах должны появиться записи о получении webhook

### Метод 3: Проверка в личном кабинете YooKassa

1. Откройте https://yookassa.ru/my
2. **Интеграция** → **HTTP-уведомления**
3. Внизу страницы есть раздел **"История отправки уведомлений"**
4. Здесь вы увидите все отправленные webhook'и и их статусы

## 🔍 Мониторинг и отладка

### Проверка статуса webhook в YooKassa

В разделе **"История отправки уведомлений"** вы увидите:

- ✅ **Зеленая галочка** - уведомление успешно доставлено (HTTP 200)
- ❌ **Красный крестик** - ошибка доставки (не HTTP 200)
- 🔄 **Часы** - повторная попытка отправки

### Типичные проблемы и решения

#### Проблема 1: Webhook не приходят

**Причины:**
- Неправильный URL
- Сервер не доступен
- Блокировка firewall

**Решение:**
1. Проверьте URL: `https://tonebal.org/api/webhooks/yookassa`
2. Проверьте доступность: `curl https://tonebal.org/api/health`
3. Убедитесь, что Vercel развернут и работает

#### Проблема 2: Webhook приходят, но возвращают ошибку

**Причины:**
- Ошибка в коде обработки
- Проблемы с базой данных
- Таймаут запроса

**Решение:**
1. Проверьте логи Vercel
2. Убедитесь, что переменные окружения установлены
3. Проверьте, что `YOOKASSA_SECRET_KEY` правильный

#### Проблема 3: Подписка не активируется

**Причины:**
- Webhook не обрабатывается
- Ошибка в metadata платежа
- Проблема с логикой активации

**Решение:**
1. Проверьте логи: должно быть сообщение "✅ Subscription activated"
2. Проверьте metadata в платеже (должны быть `user_id` и `nosology`)
3. Проверьте API: `GET /api/subscriptions/{user_id}/{nosology}`

## 🔐 Безопасность

### Реализованные меры безопасности:

1. **Проверка типа уведомления** - только `type: "notification"`
2. **Верификация через API** - проверка статуса платежа через официальный API
3. **Проверка IP** (опционально) - только с IP-адресов YooKassa
4. **HTTPS** - шифрование всех данных
5. **Идемпотентность** - безопасная обработка повторных уведомлений

### Рекомендации:

1. **Включите проверку IP** в production (раскомментируйте код в `server.js`)
2. **Логируйте все webhook'и** для аудита
3. **Используйте базу данных** вместо in-memory хранилища
4. **Настройте мониторинг** для отслеживания ошибок
